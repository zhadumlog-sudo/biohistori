# БиоИстория — биологические происшествия в СССР и России

Статический сайт на HTML, CSS и JavaScript.

## Файлы
- `index.html` — структура страницы
- `style.css` — оформление и адаптация под мобильные устройства
- `script.js` — карточки событий, поиск и всплывающие окна с историями

## Как открыть
Откройте `index.html` в браузере. Интернет нужен только для загрузки шрифта Google Fonts; сайт работает и без него.

## Публикация на GitHub Pages
1. Создайте новый репозиторий на GitHub.
2. Загрузите в корень репозитория `index.html`, `style.css` и `script.js`.
3. Откройте **Settings → Pages**.
4. В разделе публикации выберите **Deploy from a branch**, ветку `main` и папку `/ (root)`.
5. Нажмите **Save** и подождите, пока GitHub Pages опубликует сайт.

Примечание: список содержит как конкретные происшествия, так и обобщённые материалы о природных очагах инфекций и биологических рисках. В карточках это отмечено отдельно; источники приведены для дальнейшего изучения.
